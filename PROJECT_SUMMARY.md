## 📦 Installation Instructions

### For End Users
1. Download the theme folder: `ai-premium-theme`
2. Compress it into a .zip file: `ai-premium-theme.zip`
3. Go to WordPress admin: Appearance > Themes > Add New
4. Click "Upload Theme" and select the .zip file
5. Click "Activate" once installed

### For Developers
1. Copy the `ai-premium-theme` folder to `/wp-content/themes/`
2. Activate via Appearance > Themes in WordPress admin
3. Customize as needed or create a child theme
