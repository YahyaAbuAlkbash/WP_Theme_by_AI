## 📚 How to Use New Features

### Accessing the Customizer
1. Go to **Appearance > Customize**
2. Explore new panels: Header, Typography, Blog, Footer, Social Media
3. Make changes and see live preview
4. Click "Publish" to save

### Adding Portfolio Items
1. Go to **Portfolio > Add New** in admin
2. Add title, description, featured image
3. Assign to categories
4. Publish
5. View at yoursite.com/portfolio/

### Importing a Demo
1. Go to **Appearance > Demo Import**
2. Choose Business, Blog, or Shop demo
3. Click "Import [Demo Name]"
4. Wait for completion
5. Your site is ready!

### Using the Child Theme
1. Upload both parent and child themes
2. Activate the **child theme** (parent must remain installed but inactive)
3. Edit child theme files safely
4. Your changes won't be lost on updates
