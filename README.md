## 🚀 Quick Start

### For End Users

1. **Download the Theme**
   - Navigate to the `ai-premium-theme` folder
   - Download or compress the entire folder as a .zip file

2. **Install in WordPress**
   - Go to: Appearance > Themes > Add New
   - Click "Upload Theme"
   - Select your .zip file and click "Install Now"
   - Click "Activate" once installed

3. **Customize**
   - Go to Appearance > Customize
   - Set up your logo, colors, and menus
   - Add widgets and configure settings

### For Developers

1. **Clone or Download**
   ```bash
   git clone https://github.com/YahyaAbuAlkbash/WP_Theme_by_AI.git
   ```

2. **Copy Theme**
   ```bash
   cp -r ai-premium-theme /path/to/wordpress/wp-content/themes/
   ```

3. **Activate in WordPress**
   - Go to Appearance > Themes
   - Find "AI Premium Theme" and activate
