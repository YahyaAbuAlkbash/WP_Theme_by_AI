### Design System

#### Colors
- **Primary**: #2563eb (Blue)
- **Secondary**: #7c3aed (Purple)
- **Text Dark**: #1e293b
- **Text Medium**: #64748b
- **Background**: #f8fafc

#### Typography
- **Headings**: 700-800 weight, gradient effects
- **Body**: 400 weight, 1.6-1.8 line height
- **Small Text**: 0.875-0.9rem

#### Spacing
- **Small**: 0.5rem
- **Medium**: 1rem-1.5rem
- **Large**: 2rem-3rem
- **XLarge**: 4rem-5rem

#### Borders
- **Radius**: 8px-16px for cards
- **Width**: 1px-2px for borders

#### Shadows
- **Small**: 0 4px 12px rgba(0, 0, 0, 0.05)
- **Medium**: 0 8px 20px rgba(0, 0, 0, 0.1)
- **Large**: 0 20px 40px rgba(0, 0, 0, 0.15)

#### Animations
- **Duration**: 0.3s standard, 0.4s complex
- **Easing**: ease, cubic-bezier(0.4, 0, 0.2, 1)
- **Hover Lift**: translateY(-5px to -8px)
