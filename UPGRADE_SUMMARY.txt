HOW TO USE NEW FEATURES
═══════════════════════════════════════════════════════════════

CUSTOMIZER:
→ Go to Appearance > Customize
→ Explore new panels (Header, Typography, Blog, etc.)
→ Make changes and preview live
→ Click Publish

CUSTOM POST TYPES:
→ Portfolio: Add via Portfolio > Add New
→ Team: Add via Team > Add New
→ Services: Add via Services > Add New
→ Testimonials: Add via Testimonials > Add New

DEMO IMPORTER:
→ Go to Appearance > Demo Import
→ Choose Business, Blog, or Shop
→ Click Import button
→ Wait for completion

CHILD THEME:
→ Upload both parent and child themes
→ Activate child theme (not parent)
→ Customize safely in child theme files
